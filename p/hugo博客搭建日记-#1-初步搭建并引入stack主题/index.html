Hugo博客搭建日记 #1 - 初步搭建并引入Stack主题

使用Hugo工具生成静态页面，并导入Stack主题

Step 01 - 搭建环境准备

在一切的一切开始之前，你得先需要准备好搭建所需的环境，这样你才可以搭建你的Blog

1.1 下载 Hugo

  • 前往 [Hugo Github Releases]选择最新发行版下载，下载完成后进行解压操作即可

    GitHub的访问取决于你当地的网络情况，会有很大概率连接不上，请确保你具备魔法上网的能力，当然，这里也提供了Hugo的下载链接[版本为 v0.139.2 ，可自行按需下载]

    点此跳转Onedrive下载

  • Windows下载的版本为：hugo_extended_xxxx_windows_amd64.zip

Step 02 - 搭建博客

2.1 创建博客

  1. 在一个你心仪的位置新建一个文件夹并将解压出来的hugo.exe移动至此文件夹，随后在该文件夹的地址栏输入cmd后按下Enter键唤起命令指示符

  2. 在弹出的命令指示符窗口中输入hugo new site xxx(文件夹名字)创建你的hugo博客文件夹

  3. 创建完成后输入命令cd xxx(建立的文件夹名称)切换目录，并将**hugo.exe**复制至该文件夹下
